# 桌面工具箱 v0.1.0

一个简洁的桌面效率工具（Go + Wails v2，界面为中文、浅色、类 Apple 风格），支持 **Windows 10/11** 和 **macOS 12+（Apple 芯片 / Intel）**，完全离线运行。
安装后常驻系统托盘（macOS 为菜单栏图标），通过全局快捷键一键调用。

下表描述的是 Windows 版；macOS 版功能范围相同，差异见下文 [macOS 版](#macos-版)。

## 功能

| 工具 | 说明 |
| --- | --- |
| **文件搜索** | 按文件名搜索（多个关键词用空格分隔，需全部命中，不区分大小写），范围可选“所有磁盘”（固定盘 + 可移动盘）或指定文件夹（也可把文件夹拖进窗口）。可选“搜索文件内容”：支持 txt / md / csv / 代码 / 日志 / json / xml / html 等文本（自动识别 UTF-8、UTF-16、GBK/GB18030），以及 .docx、.xlsx、.pptx、.pdf。并发遍历，自动跳过 Windows、$Recycle.Bin、System Volume Information、node_modules、.git 等系统/隐藏/依赖目录；内容搜索单文件上限 50MB；结果实时流式显示（上限 5000 条），可随时停止；可按名称/大小/时间排序；可按扩展名筛选。双击打开文件（系统默认程序）；右键菜单：打开 / 打开所在文件夹（资源管理器中选中）/ 复制路径。右侧**预览面板**显示提取出的文字，所有匹配处以**黄色高亮**，可“上一处/下一处”（F3 / Shift+F3）跳转——只读预览，**绝不修改原文件**。 |
| **截图** | 快捷键或按钮触发，冻结所有显示器画面，拖动框选区域（实时显示尺寸，可拖动移动选区，单击选中整个屏幕）。工具栏：**复制**（同时写入 CF_DIB 和 PNG 格式，可直接粘贴到 Word / 微信 / 邮件，Word 会自动缩放到页面宽度）、**保存**（PNG，默认桌面，可选路径）、**取消**。Esc 取消，右键重选，回车/双击/Ctrl+C 复制，Ctrl+S 保存。Per-Monitor V2 DPI 感知，按物理像素截图，支持多显示器/不同缩放比例。截图同时记入剪贴板历史。 |
| **超级复制** | 后台记录剪贴板历史（文字和图片，最近 100 条，置顶的不计入淘汰），保存在 `%APPDATA%\DesktopToolbox\clipboard`。支持搜索、置顶、删除、清空（保留置顶）、暂停记录；点击条目即复制回剪贴板；“多选”（或 Ctrl+点击 / 空格）按选择顺序把多条文本用换行合并复制。`Ctrl+Shift+V` 弹出小窗口列表：↑↓ 选择、Enter 复制并隐藏、Esc 关闭。会遵守密码管理器设置的“不记录”标记（ExcludeClipboardContentFromMonitorProcessing / CanIncludeInClipboardHistory）。 |
| **格式转换** | PDF → Word（pdf2docx）与 Markdown → Word（Python-Markdown + python-docx，自写转换器：标题、粗体/斜体/删除线、行内代码、代码块、有序/无序/嵌套列表、引用、表格（含对齐）、超链接、本地图片（自动限制为页面宽度）、分隔线；中文字体设为微软雅黑；Markdown 自动识别 UTF-8/GBK）。支持拖放或选择多个文件批量转换，输出到原文件旁（重名自动加 (1)(2)…）或指定文件夹，显示进度，完成后可“打开文件 / 所在文件夹”。扫描件（纯图片）PDF 会明确提示“需要 OCR，本工具不包含 OCR”；加密 PDF 也会提示。使用随附的嵌入式 Python 3.12 运行，后台无控制台窗口。 |
| **录屏** | 内置 FFmpeg（gdigrab）。模式：全屏（鼠标所在显示器）/ 选择区域（复用截图选框）/ 预设 1920×1080、1280×720（固定大小框跟随鼠标，单击放置）。H.264（libx264 ultrafast，yuv420p，宽高自动取偶数），默认 30fps（可选 15/60），可选是否录制鼠标指针；可选麦克风（dshow，默认不录音）。录制时屏幕上方显示悬浮计时条和“停止”按钮（可拖动），区域录制时显示红色边框；两者都设置了“不被捕获”（Win10 2004+），不会出现在视频中。停止时向 FFmpeg 发送 `q` 正常收尾，保存为 `桌面\录屏_日期_时间.mp4`。 |

不包含（按需求明确排除）：OCR、翻译、去水印、语音/会议记录。

## 全局快捷键

| 功能 | Windows | macOS |
| --- | --- | --- |
| 显示 / 隐藏主窗口 | `Alt + Space` | `⌥ Option + Space` |
| 截图 | `Ctrl + Alt + A` | `⌃ Control + ⌥ Option + A`（避开系统 `⌘⇧3/4/5`） |
| 剪贴板历史（小窗口） | `Ctrl + Shift + V` | `⌘ Command + ⇧ Shift + V` |

快捷键目前不可自定义（与 Windows 版一致）。

若快捷键被其他程序占用，启动时会提示，“设置与快捷键”页面会显示状态。
关闭主窗口只是隐藏到托盘；托盘图标左键显示主窗口，右键菜单可截图、打开剪贴板历史、录屏、退出。
程序为单实例：重复启动会唤出已运行的窗口。可在设置中开启“开机自动启动（后台运行）”。

## 安装（Windows）

运行 `dist/桌面工具箱-Setup-x64.exe`（需要管理员权限，默认安装到 `C:\Program Files\DesktopToolbox`，创建开始菜单和桌面快捷方式）。
也可以使用便携版 `dist/桌面工具箱-便携版-x64.zip`，解压后运行 `DesktopToolbox.exe`。

系统要求：Windows 10 / 11（x64），Microsoft Edge WebView2 运行时（Win11 自带；Win10 一般已随 Edge 安装。若缺失，安装程序会尝试在线安装，此步骤需要联网）。

卸载：控制面板 / 设置 → 应用 → 桌面工具箱，卸载时会询问是否删除剪贴板历史与设置。

## macOS 版

### 安装与首次打开

从 GitHub Release 下载对应芯片的 DMG：Apple 芯片（M1/M2/M3/M4）选 `DesktopToolbox-<版本>-macOS-arm64.dmg`，Intel 芯片选 `…-macOS-x64.dmg`。
打开 DMG，把“桌面工具箱”拖进“应用程序”。

本程序没有 Apple 开发者证书，只做了 ad-hoc 签名（`codesign --force --deep -s -`）、未经公证，第一次打开会被 Gatekeeper 拦截：

- **macOS 14 及更早**：在“应用程序”中按住 Control 点按（或右键）“桌面工具箱” → **打开** → 打开。
- **macOS 15 及更新**（右键打开已被系统取消）：先双击一次，再到 **系统设置 → 隐私与安全性**，在页面底部点 **仍要打开**。
- 或者在“终端”执行：`xattr -cr /Applications/桌面工具箱.app`（清除隔离属性，最省事）。

### 需要的系统权限

| 权限 | 何时需要 | 说明 |
| --- | --- | --- |
| 屏幕录制 | 截图、录屏 | 首次使用时系统弹窗；在 **系统设置 → 隐私与安全性 → 屏幕录制** 打开“桌面工具箱”后需**退出并重新打开**程序。未授权时程序会提示并打开该设置页（`x-apple.systempreferences:com.apple.preference.security?Privacy_ScreenCapture`）。“设置与快捷键”页显示授权状态并有“打开系统设置”按钮。macOS 15 起系统会定期再次确认。 |
| 麦克风 | 录屏时选择了麦克风 | 首次录音时系统弹窗。 |
| 文件与文件夹（桌面/文稿/下载、可移除宗卷、网络宗卷） | 文件搜索、格式转换 | 首次访问时系统弹窗。 |
| 辅助功能 | **不需要** | 全局快捷键使用 Carbon `RegisterEventHotKey`，不需要辅助功能权限；本程序也不模拟按键（剪贴板小窗口复制后自动隐藏并把焦点还给之前的应用，按 `⌘V` 粘贴）。 |

由于是 ad-hoc 签名，每次更新到新版本后，macOS 可能要求重新授予“屏幕录制”等权限（权限与签名绑定）。

### 与 Windows 版的差异

| 功能 | macOS 实现 |
| --- | --- |
| 文件搜索 | “整台电脑”= 用户主目录 + /Applications + /Users/Shared + /Volumes 下挂载的其他磁盘（U 盘、移动硬盘、网络盘）；不搜索 /System、/Library、/usr、/private 等系统目录，~/Library（隐藏）、.Trash、node_modules、.git 等也跳过；.app 等“包”可按名称搜到但不进入其内部。**整台电脑 + 只搜文件名**时使用 Spotlight 索引（`mdfind`），秒出结果；Spotlight 不可用时自动回退到实时遍历。内容搜索与“指定文件夹”始终实时遍历。“打开所在文件夹”= 在访达中显示（`open -R`）。 |
| 截图 | 调用系统 `/usr/sbin/screencapture -i`：原生框选外观，自动处理 Retina/多显示器；框选时按空格可切换为窗口截图，Esc 取消。截好后**自动复制**到剪贴板（同时写入 PNG 与 TIFF，可直接粘贴到 Word / Pages / 微信 / 邮件）并记入剪贴板历史；界面结果栏可“另存为…”保存 PNG（默认桌面）。 |
| 超级复制 | 每 0.5 秒轮询 `NSPasteboard.changeCount`（macOS 没有剪贴板变化通知），记录文字和图片；遵守 nspasteboard.org 约定，忽略密码管理器标记的 `org.nspasteboard.ConcealedType` / `TransientType` / `AutoGeneratedType`，访达复制文件（文件 URL）不记录。历史保存在 `~/Library/Application Support/DesktopToolbox/clipboard`（格式与 Windows 版相同）。多选可用 `⌘ + 点击`。 |
| 格式转换 | 内置 python-build-standalone 的 CPython 3.12（可重定位）+ pdf2docx / PyMuPDF 1.26 / python-docx / Markdown，与 Windows 版共用 `resources/scripts/convert.py`。 |
| 录屏 | 内置静态 FFmpeg（avfoundation 输入，`-capture_cursor`，libx264 ultrafast，yuv420p），按显示器采集。“选择区域”/预设尺寸使用原生全屏半透明遮罩（cgo 实现的无边框 NSWindow）在**鼠标所在显示器**上框选，单击 = 整个屏幕，Esc 取消；用 crop 滤镜按比例裁剪（与 Retina 缩放无关），预设模式再缩放到精确的 1920×1080 / 1280×720。录制时屏幕顶部显示悬浮计时条（`NSWindowSharingNone`，不应出现在视频中）并在菜单栏图标旁显示计时，菜单中也可“停止录屏”。停止时向 FFmpeg 发送 `q` 正常收尾，保存为 `~/Desktop/录屏_日期_时间.mp4`。可选麦克风（avfoundation 音频设备）。 |
| 托盘 | 菜单栏图标（cgo `NSStatusItem`）：显示主窗口 / 截图 / 剪贴板历史 / 录屏 / 停止录屏 / 退出。程序坞图标保留（`LSUIElement=false`），点击程序坞图标可重新打开主窗口。 |
| 单实例 | Wails `SingleInstanceLock`（重复启动会唤出已运行的窗口）。 |
| 自动启动 | “登录时自动启动”写入 `~/Library/LaunchAgents/com.hark.desktoptoolbox.plist`（带 `--background`，不显示窗口）。 |
| 数据目录 | `~/Library/Application Support/DesktopToolbox`。 |

Bundle ID：`com.hark.desktoptoolbox`；最低系统 macOS 12（opencv/numpy 轮子按 `macosx_12_0` 选择）。

### macOS 构建（GitHub Actions）

macOS 程序需要 cgo + macOS SDK，只能在 Mac 上编译。仓库自带工作流 `.github/workflows/build-macos.yml`：

- **触发**：推送 `v*` 标签，或在 Actions 页面手动运行（可勾选“创建 Release”“同时构建 Windows”）。
- **check**（ubuntu）：gofmt、`go vet`（linux / windows / darwin 无 cgo）、单元测试。
- **macos**（矩阵：arm64 用 `macos-26`，x64 用 `macos-15-intel`，均为原生运行器）：执行 `bash scripts/build-macos.sh <arch>`：
  1. 下载 python-build-standalone `cpython-3.12.16+20261110-<aarch64|x86_64>-apple-darwin-install_only`，精简；
  2. `pip install --target … --platform macosx_12_0_<arch> --only-binary=:all:` 安装 pdf2docx、PyMuPDF 1.26.x 等轮子，预编译 .pyc；
  3. 下载 ffmpeg.martin-riedl.de 的静态 FFmpeg（arm64 / amd64）；
  4. `wails build -platform darwin/<arm64|amd64>`（Info.plist 模板见 `build/darwin/Info.plist`，图标由 `build/appicon.png` 生成）；
  5. 把 python / ffmpeg / scripts 放入 `.app/Contents/Resources`，改名为“桌面工具箱.app”，逐个 ad-hoc 签名 Resources 中未签名的 Mach-O，再 `codesign --force --deep -s -` 整个 .app；
  6. 自检（运行内置 Python 的 selftest，并实际转换 sample.md / text.pdf；x64 版在 Rosetta 可用时同样自检），用 `hdiutil` 打包 DMG（含“应用程序”快捷方式与安装说明）。
  产物 `DesktopToolbox-<版本>-macOS-arm64.dmg` / `…-macOS-x64.dmg` 作为 artifact 上传。
- **windows**（可选，ubuntu）：运行 `scripts/build.sh`，产物改为 ASCII 文件名 `DesktopToolbox-<版本>-Windows-Setup-x64.exe` / `…-Portable-x64.zip`。
- **release**：标签推送或勾选“创建 Release”时，用 `softprops/action-gh-release` 把所有安装包附加到 Release（手动运行时标签取 `v` + wails.json 中的版本）。

之所以是两个按芯片区分的 DMG 而不是一个 universal：内置 Python 的 numpy / opencv / PyMuPDF 轮子按架构分发，合并成 universal 需要逐个 `lipo`，体积也会翻倍。

在 Mac 上本地构建：安装 Xcode 命令行工具、Go ≥ 1.26、Python 3.12、`go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.1`，然后 `bash scripts/build-macos.sh arm64`（或 `x64`）。

## 从源码构建 Windows 版（Linux 交叉编译）

已在 Debian 13 aarch64 上验证。需要：Go ≥ 1.26、Wails CLI v2.17、NSIS（makensis）、Python 3.12（用于下载 Windows 轮子、预编译 .pyc、运行测试）、zip/unzip、curl。

```bash
# 一次性准备
curl -sSL https://go.dev/dl/go1.27.4.linux-arm64.tar.gz | tar xz -C /workspace/tools   # 或 amd64 版本
source /workspace/tools/env.sh            # 设置 GOROOT/GOPATH/PATH
go install github.com/wailsapp/wails/v2/cmd/wails@v2.17.1
sudo apt-get install -y nsis zip unzip
python3 -m venv /workspace/tools/pyenv && /workspace/tools/pyenv/bin/pip install pdf2docx==0.5.13 python-docx markdown "PyMuPDF<1.27" "opencv-python-headless<4.13" "numpy<2.4"   # 仅用于测试

# 一键构建（下载组件 → 准备内置 Python/FFmpeg → 测试 → 编译 → NSIS 安装包 → 便携版 zip）
bash scripts/build.sh
```

构建脚本步骤：

1. 下载 `python-3.12.10-embed-amd64.zip`、gyan.dev FFmpeg essentials（只取 `ffmpeg.exe`）、用
   `pip download --platform win_amd64 --python-version 3.12 --only-binary=:all:` 下载 pdf2docx、python-docx、markdown、PyMuPDF 1.26、opencv-python-headless、numpy 等 Windows 轮子，以及 `msvc-runtime`（提供 msvcp140.dll，PyMuPDF 需要）。
2. 解压嵌入式 Python，改写 `python312._pth` 启用 `Lib\site-packages` 与 `import site`，把轮子解压进 site-packages，复制 VC++ 运行库，预编译 .pyc（unchecked-hash）。
3. `go vet`（linux、windows 与 darwin 类型检查）+ `go test ./internal/...`（含调用本机 Python 测试转换脚本、调用本机 ffmpeg 测试录屏收尾逻辑）。
4. `wails build -platform windows/amd64 -nsis -skipbindings -trimpath -ldflags "-s -w"`（CGO_ENABLED=0，纯 Go）。
5. 安装包复制为 `dist/桌面工具箱-Setup-x64.exe`。
6. 生成便携版 `dist/桌面工具箱-便携版-x64.zip`。

单独运行测试：

```bash
go test ./internal/...                                   # 搜索、内容提取、剪贴板存储、DIB 编解码、录屏参数、转换
/workspace/tools/pyenv/bin/python resources/scripts/convert.py --mode md2docx --input tests/samples/sample.md --output /tmp/a.docx
```

界面预览（无需 Windows）：`chromium --headless --screenshot=ui.png "file://$PWD/tests/ui/preview.html?view=search"`（view 可为 search / shot / clipboard / convert / record / settings / popup），使用 `tests/ui/mock.js` 模拟后端。

## 已知限制

- 文件内容搜索是实时遍历（不建索引），全盘内容搜索会比较慢；不支持旧版 .doc/.xls/.ppt。
- PDF 文本提取（搜索/预览）使用纯 Go 库，对部分使用特殊编码字体的中文 PDF 可能提取不全；PDF→Word 转换使用 PyMuPDF，不受此影响。
- PDF→Word 的版式还原取决于 pdf2docx，复杂排版可能需要手动调整；扫描件需要 OCR（不包含）。
- 录屏不录制系统声音（仅可选麦克风）；悬浮条“不被录入”需要 Win10 2004 及以上。
- WebView2 运行时缺失且无网络时无法启动（可预先安装 WebView2 离线包）。
- macOS：未公证，首次打开需要手动放行（见上文）；更新版本后可能需要重新授予“屏幕录制”权限。
- macOS：区域录制只能在一个显示器内框选（avfoundation 按显示器采集）；录屏不录系统声音。
