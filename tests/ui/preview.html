使用方法

  • 按住鼠标左键拖动选择区域，拖动选区可移动位置；单击则选中整个屏幕
  • 复制（或双击选区 / 回车 / Ctrl+C）：图片进入剪贴板，在 Word、微信、邮件中直接粘贴，Word 会自动缩放到页面宽度
  • 保存（或 Ctrl+S）：保存为 PNG，默认位置为桌面
  • 右键重新选择，Esc 取消
